## Learning Path

A practical progression through these **hands-on cybersecurity labs** is:

1. Start with **LaTeX Input** and **Python Format String** to understand dangerous input handling.
2. Study **Python Eval Is Evil** to understand the risks associated with dynamic evaluation.
3. Continue with **Python Jail Exec**, **Python PyJail 1**, and **Python PyJail 2**.
4. Explore **Python Jail Garbage Collector** for deeper Python runtime concepts.
5. Study **JavaScript Jail** and **PHP Jail** to compare sandbox concepts across languages.
6. Practice **Bash Restricted Shells** and **Sudo Weak Configuration** for Linux security.
7. Finish with **Deep Learning Malicious Model** to explore security concerns in machine-learning environments.

## How to Use the Labs

- Use these labs only in authorized CTF and training environments.
- Read each lab's objectives and scope before testing.
- Focus on understanding why a restriction or vulnerability exists.
- Record inputs, application behavior, errors, and security boundaries.
- Compare insecure behavior with appropriate defensive controls.
- For jail and sandbox exercises, study the difference between intended restrictions and actual security boundaries.
- For sudo and shell labs, consider least privilege and secure configuration.
- For ML security exercises, consider model provenance, validation, isolation, and deployment controls.
